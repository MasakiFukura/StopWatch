# 汎用マルチストップウォッチ

ブラウザだけで動く、複数同時計測に対応したストップウォッチです。  
HTML・CSS・JavaScriptのみで構成されており、インストール不要・ビルド不要で使用できます。

## 特徴

- **複数のストップウォッチを同時管理** — 最大20個まで表示できます
- **2つの動作モード** — 1つだけ動かす「切り替えモード」と、複数を同時に動かせる「同時実行モード」を選択できます
- **自由なレイアウト** — 並べ方（横優先・縦優先）、折り返し数、円のサイズを自由に変更できます
- **名称・色のカスタマイズ** — 各ウォッチに名前と色を設定できます
- **スマホ・PC両対応** — タップ操作にも対応したレスポンシブデザインです
- **外部依存なし** — `index.html` 1ファイルで完結します
- **折りたたみUI** — 使い方・設定エリアはそれぞれ折りたたみ可能で、画面を広く使えます

## 使い方

### 基本操作

|操作|動作|
|---|---|
|円をタップ／クリック|ストップウォッチの開始・停止|
|名称欄を編集|ストップウォッチに名前を付ける|
|色ボタン（丸）を押す|カラーピッカーが開き、色を変更できる|
|リセットボタン|全ウォッチを停止し、時間をゼロに戻す|

### キーボード操作

|キー|動作|
|---|---|
|Tab|名称欄 → 色ボタン → 次のウォッチへ移動|
|Space（色ボタン選択中）|カラーピッカーを開く|

### 動作モード

**切り替えモード**（初期値）  
常に1つだけ動きます。別のウォッチを押すと、現在動いているものが自動的に止まります。複数の対象を交互に計測するときに便利です。

**同時実行モード**  
複数のウォッチを同時に動かせます。それぞれ独立して開始・停止できます。

### 設定項目

|設定|説明|初期値|
|---|---|---|
|ストップウォッチ数|表示する個数（1〜20）|4|
|サイズ|円の直径（10〜1000 px）|160|
|配置の流れ|横方向優先 / 縦方向優先|横方向優先|
|折り返し数|1行（または1列）あたりの個数（1〜10）|2|
|動作モード|切り替えモード / 同時実行モード|切り替えモード|

## 時間の表示形式

```text
mm:ss.x        （例: 03:27.4）
hh:mm:ss.x     （1時間以上の場合）
```

## ファイル構成

```text
index.html   — すべての実装が入った単一ファイル
仕様書.md    — 機能仕様
README.md    — このファイル
```

## 動作環境

モダンブラウザ（Chrome・Firefox・Safari・Edge）であれば動作します。  
インターネット接続・サーバーは不要です。`index.html`をブラウザで開くだけで使えます。
